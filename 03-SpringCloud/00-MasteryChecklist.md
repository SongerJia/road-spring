## 3. OpenFeign 原理？

**锚点**：官方文档 Spring Cloud OpenFeign

- [ ] **及格**：Feign = **声明式 HTTP 客户端**——定义一个接口 + `@FeignClient`，调用接口就像调用本地方法，实际发 HTTP 请求
- [ ] **良好**：及格 + 能说出实现——**动态代理**（`FeignClientFactoryBean` 为接口生成代理，方法调用 → 拼装请求 → 发出去）、**内置负载均衡**（集成 LoadBalancer，按服务名解析）+ **超时配置**（connect/read 超时）+ 日志级别
- [ ] **精通**：良好 + 能应对追问——Feign 与 **RestTemplate / WebClient** 的对比取舍、怎么开启**熔断降级**（`fallback` / `fallbackFactory` 区别）、`RequestInterceptor` 做**统一鉴权/透传**、Feign 的**坑**（返回值序列化、接口方法不支持重载、复杂参数要用 `@RequestBody`）

## 4. 熔断 / 降级 / 限流（Sentinel）？

**锚点**：官方文档 Sentinel / Hystrix

- [ ] **及格**：三个概念——**熔断**（下游故障时快速失败，不拖垮自己）、**降级**（故障时返回兜底结果）、**限流**（控制流量防止打垮）；Sentinel 是阿里开源的主流实现
- [ ] **良好**：及格 + 能说出 Sentinel 机制——**熔断状态机**（关闭 → 打开 → 半开，滑动窗口统计）、**限流算法**（固定窗口/滑动窗口/令牌桶/漏桶）、**隔离方式**（信号量隔离 vs 线程池隔离，Sentinel 用信号量）+ 控制台与**规则持久化**
